# Web 新手引导

首次打开工作台会显示一张非强制欢迎卡。选择“带我看看”开始四步指南，也可以选择“先自己看看”；之后随时从页首“使用指南”重新打开。

## 四步内容与下一步

| 步骤 | 需要了解的事 | 导览中的页面入口 |
| --- | --- | --- |
| 看线索 | 传统挖矿、节点 / 算力贡献、测试网 / 空投任务分别展示；发现线索不等于核验后的机会，“未开盘”需要发行和交易证据 | 看看项目线索 → 发现项目 |
| 看条件 | 查看本机设备与已有偏好；电价、预算、技能和时间未知时保留未知，不要求填表才能继续 | 查看设备与偏好 → 档案与设置 |
| 看预检 | 扫描与预检分别记录；“待补资料”和“条件不匹配”解释条件缺口，不代表真实挖矿失败 | 看看预检记录 → 运行记录 |
| 看请求 | 选择项目，点击“交给 Agent 检查”，查看进度与来源；完成后在“检查后的准备方案”查看事实、缺项与模拟，真实执行尚未实现 | 查看参与与运行 → 参与与运行 |

第一步明确提示：可以自行点击页首“扫描公开来源”刷新线索，它只读取公开信息。指南不自动点击扫描，也不自动保存偏好、启动观察、执行模拟、安装软件或进行任何费用操作。全部“查看”按钮只切换本地页面。

第四步选择“读完了”后，显示“现在可以开始查看线索了”。这仅代表读完使用指南，不把配置、研究、项目参与或挖矿标为完成。用户可以查看项目列表，也可以回到工作台。

## 进度、关闭与恢复

- 首次欢迎卡显示于所有页面，不自动弹出模态窗口。跳过会记住这个选择。
- 每步均有步骤指示、上一步、下一步和关闭入口。第一步的上一步不可用。
- 查看对应页面会收起指南并保存当前步骤；页首入口显示“继续”与步骤数。
- 正在阅读时刷新页面，会恢复当时打开的步骤；关闭或按 Esc 后刷新不会强行重开。
- 完成后再次从页首打开，可以从第一步重新阅读。
- 使用原生 `dialog` 处理键盘焦点与 Esc；关闭后焦点回到发起按钮，按钮不可见时回到常驻“使用指南”。项目详情、参与计划、观察确认与指南互斥显示。
- 每 15 秒的数据刷新不重建指南内容，阅读进度和焦点独立于服务状态。服务暂时不可用时仍可阅读指南。

进度保存在当前浏览器、当前源的 `localStorage`，键为 `prospect_onboarding_v1`，值包含 `version`、`status`、`step`、`open`，不包含用户档案和项目数据。旧版本、损坏或非法进度按首次访问处理。浏览器禁止存储时降级为本页内记忆，不报错；这种情况下刷新后无法保留进度。

## 验证范围

静态检查已执行：`node --check web/app.js` 通过；HTML 无重复 ID，JS 中 18 个直接引用的指南 ID 及全部 ARIA 引用目标均存在。浏览器验收由本轮主任务在独立测试端口完成并记入工程状态及证据文件，不能用静态检查替代键盘、移动端和真实交互验证。

浏览器验收应覆盖首次欢迎、跳过后刷新、常驻入口重开、前后步骤、阅读中刷新恢复、页面入口不产生业务请求、完成屏、Esc 与焦点恢复、服务轮询、390px 窄屏以及无法使用 `localStorage` 的降级。验收使用隔离数据；真实工作区保留用户首次进入时的欢迎体验。
