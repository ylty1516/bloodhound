# 简化参与入口

2026-11-08。用户希望入口更明显、操作更简单。

左侧「开始参与」是统一入口，地址仍为 `#requests`。其他页面页首「＋ 开始一个项目」、首页按钮、项目列表每行「开始参与」都会进入这里；项目行直接带入所选项目，点击名称仍可阅读资料。

本页只需选择项目，Agent 根据实际连接宿主自动识别，再按下方的大按钮继续。步骤为「选择项目 → Agent 检查 → 启动运行」。手动改用其他宿主或API放在折叠的“其他检查方式”中；详见 [自动识别规则](AUTOMATIC_AGENT.md)。发起检查后原地显示排队/实际阶段、活动时间和停止入口；完成后给出具体下一步。模型未配置时直接提供配置入口，失败或资料变化时可重试。手动检查没有本地每日次数/token上限。项目和临时选择在当前浏览器会话保留，刷新仍可继续。

已接入运行方式的项目可直接打开原有运行范围确认；版本安全核验、资源、地址等仍由服务器检查，必须手动确认一次才启动。未接入运行方式时明确说明，避免反复检查却没有可执行下一步。历史方案即使后续检查失败仍可查看。不新增自动挖矿或定时执行能力。

「运行中心」首屏展示真实项目记录和明显的新建入口。诊断运行归入折叠的「体验与排查 · 不会挖矿」；旧自检记录、日志、回执和手动自检功能保留，不再默认占满真实项目区域。扫描按钮退为次要操作，只在总览、发现、来源页面显示。

验证：16项参与状态断言、4项原有交互回归、22项HTTP服务测试通过。隔离5714端口使用本地模拟DeepSeek接口，浏览器实测项目选择→提交→进度→报告→未接入说明，模型未启用时的配置入口，以及从列表直接带入项目。手机390×844设置下文档可用宽度376px、滚动宽度376px，无横向溢出。正式服务仅查看状态和页面，未发起新的模型检查、自检或真实项目运行。

证据：`evidence/participation-flow-tests.log`、`participation-service-tests.log`、`participation-runtime.json`、`participation-ui-qa.json`、`participation-mobile-qa.png`、`participation-start.png`。
