# Prospect 深色研究工作台

更新：2026-11-06，Asia/Shanghai。用户明确否定上一版视觉，并选择“深色研究工作台”。本轮是基于真实产品状态的视觉重做与参与请求入口改造，不是营销展示页。

## 审计与设计取向

旧版为灰白内容区、深绿侧栏、四个大指标块；七日观察和设备信息先于项目列表，首次看到的记录又把开发验证的模拟阻断与用户行为混在一起。问题在于信息优先级、稀疏卡片和失败语义，而不只是颜色。

新的取向是个人项目研究工作台。用户随后要求更柔和的视觉与交互，并加入新手引导：当前采用略提亮的深色、低饱和鼠尾草绿与较舒展的中文排版。保留原生 HTML/CSS/JS、hash 路由、品牌名称和字段；没有新增框架、远程字体或图片依赖。

已阅读 design-taste-frontend 技能，其明确说明密集产品工作台不属于营销页模板适用范围。因此只采用审计、主题锁定、对比、键盘与状态反馈原则；不套用营销 hero、图片数量、滚动动画或页脚限制。用户明确选择深色，不自动切回系统浅色。

## 新的信息与交互

“参与与运行”是主导航入口。首页提供“选择项目并检查条件”，每行项目提供“查看与预检”。详情顶部现以“交给 Agent 检查”为主操作，可选择四种宿主；“仅做本地规则预检”作为次操作。Agent 检查显示排队/运行/取消/失败、带来源的七项报告、未知项和实测用量。原生 CLI 调用与需要宿主领取的方式明确区分；报告完成不直接创建运行任务，实际执行尚未实现。具体范围见 [AGENT_CHECKS.md](AGENT_CHECKS.md)。

页面与指南步骤采用原生 Web Animations：透明度 0.58→1、纵向 6px→0；每块延后 35ms、最多延后 140ms、最多六块。不延迟路由更新、事件处理、焦点或真实请求。只在首次显示/实际切页时播放页面入场，15 秒轮询和同路由不重播；指南只在主动换步时过渡。快速切页、关闭指南、切入后台或启用减少动态效果会取消未完动画。hover 仅在支持悬停的设备启用，移开与键盘焦点没有等待。

动效验证见 evidence/motion-ui-check.json 与 motion-helper-check.json：浏览器捕获页面/指南的中间透明度，验证快速切页、Esc、刷新与390px布局；真实 helper 的六项 Node VM 验证覆盖错峰、取消、清理和减少动态效果分支。VM 检查不等于操作系统设置实测，静态截图也不替代动效计时。

首次访问显示轻量欢迎条，允许直接跳过；指南在页首常驻，四步说明线索、条件、预检和参与请求，关闭后可继续。它仅导航到相关页面，不替用户填写表单或点击业务操作。进度在当前浏览器本地保存，禁止存储时退回本页内记忆；完成表示已读，不代表完成配置或参与项目。手机端指南正文独立滚动，底部操作区保留。具体行为见 [ONBOARDING.md](ONBOARDING.md)。

首页参与请求区是主要决策入口。空状态明确尚无符合提请条件的项目，不虚构收益、推荐或正在运行的任务。参与请求页显示后端真实返回的项目、理由、资源、每日时间、费用、证据、奖励与待确认事项。未知费用单位和奖励不由 UI 推断。

新出现的 pending 请求首次读取时显示提示，localStorage 按请求 ID 去重；15 秒刷新不会重复弹出。侧栏数字持续展示待决定数量。浏览器存储不可用时仍使用本页内存去重，不影响请求列表。这里是应用内通知，不宣称已经发出系统通知或离线消息。

“有意参与”和“暂不参与”调用 POST /api/participation/decision。表达意向不会启动项目或授权费用，成功后立即使用服务回执更新对话框和列表，再读取新状态；旧的并行 GET 回包不会覆盖已确认决定。对话框顶部持续显示决定状态及“尚未启动任务”。pending 以外的请求只读，stale 明确要求重新核验。证据变化是否撤回或再次提请由后端决定，前端不重复计算机会资格。

运行记录分为：真实执行状态、实际公开来源采集、参与条件预检。当前版本没有真实执行；模拟 status=blocked 按 assessment 显示“待补资料”“条件不匹配”或“预检未通过”，并展示缺失字段。origin=validation 的记录默认收起，可用开关查看，不删除原始证据。页面明确没有启动挖矿，不把预检未过写成实际挖矿失败。

保留原生 dialog 的 Esc、关闭和焦点行为；参与决定完成后聚焦关闭入口。切换到不同页面时回到页面顶部，相同路由与 15 秒数据刷新不会重置滚动。刷新保留未保存表单、展开原文和稳定按钮焦点。请求/来源文字全部 textContent，外部链接仅接受无凭据 HTTPS。

参与页补充“检查后的准备方案”，从报告直达缺项、固定版本配方和模拟结果。来源页提供持续发现开关；设置页提供每日检查准入预算。表单未保存输入在轮询中保留。持续发现与七日观察共用采集，但开关分开保存；界面明确仅关闭持续发现时观察是否仍在采集。
