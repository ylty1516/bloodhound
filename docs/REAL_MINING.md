# 单次真实挖矿与结果核验

2026-11-09，北京时间。已经完成一次真实 CPU 挖矿：矿池接受 3 个份额，记账 0.000006 USDT；本轮已停止。尚未达到 1.5 USDT 付款门槛，钱包没有到账。它证明运行线路可用，不代表具有可观收益，也不能当作整个产品验收完成。

## 如何使用

1. 双击项目根目录 `Open-Prospect.cmd`，进入左侧“开始参与”。本轮已有结果时，主按钮是“查看这轮结果”。
2. 首次使用由程序核对币安 Agent 钱包 BSC 收款地址、准确的 USDT 合约、真实市场和固定矿池路线。需要登录时，点击“连接币安钱包”，在币安 App 中确认官方页面；不在网页填写私钥或助记词。
3. “再运行一轮”先展示本次收款、时间、CPU、内存、费用和矿池证书说明；确认后才启动。运行时同页显示真实阶段、算力、已接受份额和停止入口；“运行中心”提供增量日志与回执。
4. 结束后分别查看贡献、矿池记账与钱包到账。矿池余额不是钱包余额。当前未开启每日运行；浏览器关闭不会自动终止后台，停止入口和资源上限仍有效。

## 路线与授权

CPU 实际提供 RandomX 算力，unMineable 将贡献折算成 USDT，再通过 BSC 结算；USDT 本身不是可直接工作量证明挖掘的币。市场可交易只说明存在交易通道，不证明个人挖矿利润，也不能保证未来兑付、价格或流动性。

用户本次明确允许单轮限额试跑及启用矿池自动结算。没有执行钱包转账、兑换、签名，也没有授权每日挖矿。每个新运行范围独立确认，旧确认不自动扩展到其他项目、地址或长期任务。矿池约 1% 服务费，XMRig 配置 1% 开发者捐赠；电费需用户另行计入。

矿池公开 TLS 证书为自签名，本次经说明并确认后采用首次 SHA256 指纹固定，后续变化拒绝连接。这不能证明首次连接一定可信。没有关闭系统证书校验、修改杀毒设置、增加防护排除或授予管理员权限。发布包、镜像与执行脚本仅完成本路线范围的校验与审阅，不是完整二进制或操作系统安全审计。

矿池有成功付款记录后，程序才继续核对 BSC 交易：链 ID、交易成功状态、规范区块、时间、至少 12 次确认、USDT 合约 Transfer、准确接收地址和金额。当前没有成功付款，链上核验逻辑的测试通过不能替代真实到账。
